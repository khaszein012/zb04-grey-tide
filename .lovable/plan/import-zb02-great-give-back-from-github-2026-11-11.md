# Import "zb02-great-give-back" from GitHub

The repository is a public storybook-style web app (chapters, gadget/magic/globe pictures, a "give back" story) built on the same kind of app this project uses. It looks like front-end only, with no accounts or saved data.

## Steps
1. Copy every app file from the repository into this project: pages, components, styles, and all pictures in the assets folder, plus the favicon and robots file.
2. Bring over the project notes (AGENTS.md, roadmap, art-prompt docs) so earlier decisions carry across.
3. Add the packages the app needs, keeping this project's own core framework versions.
4. Open the preview and click through each chapter to confirm pages and pictures load with no errors.
5. If anything turns out to need a backend (saved data, sign-in), report it and set it up on Lovable Cloud.

## Notes
- This is a one-time copy. Later changes on GitHub will not flow in automatically; to keep things synced, connect a new repository in Project settings -> Git afterwards.
- Repository history and git metadata are not copied.
